# Tharun Lens — Personal Photography Portfolio

A responsive, premium dark photography portfolio built with plain HTML, CSS and JavaScript.

## Included
- Responsive one-page portfolio
- Hero section
- About section
- 9-photo gallery using the supplied photographs
- Full-screen lightbox with previous/next controls
- Keyboard navigation (Esc / ← / →)
- Creative focus section
- Contact section
- Email, Instagram and LinkedIn links
- Mobile navigation
- Scroll reveal animations
- No framework or build step required

## Run locally
Open `index.html` in a browser.

For best results, use a small local server such as VS Code Live Server when testing.
